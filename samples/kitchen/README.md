## Tip untuk DapurSense

- Pilih clip **medium / wide** (seluruh dapur + orang), bukan hanya close-up tangan.
- Durasi ideal uji: 10–60 detik, horizontal HD.
- Upload via UI **Video & Analisis**, atau simpan di sini lalu import.
