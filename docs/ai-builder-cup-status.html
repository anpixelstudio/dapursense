5. Urutan sisa kerja

  1. Push commit Gen AI + Docker ke GitHub (jika belum).
  2. Deploy Cloud Run (./deploy/cloudrun/deploy.sh) — awalnya stub.
  3. Isi Gemini key / Secret Manager → AI_PROVIDER=gemini.
  4. Siapkan Cloud SQL atau skenario demo dengan data seed.
  5. Rekam video demo ≤ 3 menit (masalah → live → Gemini → impact).
  6. Deck PDF juri + pilih tema (rekomendasi: Retail & Commerce).
  7. Submit di dashboard Hack2Skill sebelum 18 Oktober 2026.
